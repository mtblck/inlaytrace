# Photo fixtures

Photos for `npm run score:photos`, which scores the Poster preset. All three
come from [scikit-image's sample data](https://github.com/scikit-image/scikit-image/tree/v0.24.0/skimage/data)
(v0.24.0), re-encoded as JPEG (quality 88) to keep the repo small.

| File | What | Licence, as scikit-image records it |
| --- | --- | --- |
| `coffee.jpg` | A coffee cup on wood, 600 × 400 | CC0, by the photographer, Rachel Michetti ("No copyright restrictions") |
| `chelsea.jpg` | Chelsea the cat, 451 × 300 | CC0, by the photographer, Stefan van der Walt ("No copyright restrictions") |
| `rocket.jpg` | Falcon 9 launching DSCOVR, 640 × 427 | Public domain, released by SpaceX |
